# GitGreen 产品需求文档（PRD）

## 1 项目简介
项目名称：**GitGreen**
项目定位：纯前端三端多 GitHub 账号一站式管理工具
运行平台：Web网页端、Windows客户端（Electron）、Android客户端（WebView）
架构特点：零后端、零服务器、零Nginx、零数据库；Vue3前端直接调用GitHub官方API
主题风格：绿色主色调，支持浅色模式 / 深色模式 / 跟随系统模式

核心价值：
1. 多GitHub账号常驻共存、无需切换、无需登出
2. 所有仓库操作100%软件内闭环，不跳转浏览器、不跳转GitHub官网
3. 支持完整仓库设置、分支管理、GitHub Action、Release打包下载
4. 三端共用一套代码，轻量化、极速启动、无服务依赖

## 2 功能需求总览
### 2.1 账号管理系统（核心）
1. 支持无限添加多个GitHub PAT账号
2. 账号凭证AES本地加密存储，不上传任何服务器
3. 账号状态检测：正常 / 过期 / 失效
4. 自定义账号备注、标签、分组
5. 账号配置导出 / 导入备份
6. 多账号并行常驻，点击即切换仓库视图，无登出操作

### 2.2 仓库全局管理
1. 树形结构：账号 → 仓库列表
2. 仓库信息展示：名称、简介、语言、Stars、Forks、公开/私有、更新时间
3. 跨账号全局搜索仓库
4. 仓库收藏、置顶、自定义分组
5. 新建远程仓库、删除远程仓库

### 2.3 完整仓库设置
1. 修改仓库名称、描述、主页链接
2. 公开/私有权限切换
3. 仓库归档/取消归档
4. 开启/关闭 Issues、Wiki、Discussions
5. 修改默认分支
6. 分支保护规则配置
7. 协作者查看、添加、删除、权限配置

### 2.4 分支全生命周期管理
1. 查看所有远程分支
2. 可视化创建远程分支
3. 删除远程分支、重命名分支
4. 分支差异对比
5. 分支保护规则绑定

### 2.5 GitHub Action 流水线全功能
1. 查看所有Workflow工作流
2. 查看所有执行记录（运行中/成功/失败/取消）
3. 手动触发流水线、取消流水线
4. 实时流式查看运行日志
5. 重新运行历史流水线
6. 在线编辑、保存Workflow yml文件

### 2.6 Release版本与打包资源管理
1. 查看所有Release正式版/测试版/草稿版
2. 查看Release详情、描述、附件列表
3. 软件内直接下载所有打包资源、二进制、安装包、源码
4. 不跳转任何浏览器、不打开GitHub官网
5. 新建/编辑/删除Release

### 2.7 在线文件管理
1. 在线查看仓库文件目录结构
2. 在线预览代码、配置文件
3. 在线编辑、新增、删除远程文件
4. 直接提交到GitHub远程仓库

### 2.8 主题系统
1. 品牌主色调：绿色
2. 三种主题模式：
   - 浅色模式
   - 深色模式
   - 跟随系统自动切换
3. 主题设置本地永久保存
4. 全页面、全组件自动适配深浅色样式

## 3 三端能力区分
### Web网页端（纯静态）
- 全部远程管理功能
- 无本地Git、无本地代码拉取
- 无需服务器，直接打开HTML运行

### Windows客户端（Electron）
- 包含全部远程功能
- 支持本地Git：克隆、Pull、Push、分支切换
- 无跨域限制，全功能最完整

### Android客户端
- 全部远程运维能力
- 支持后台断点续传下载Release包
- 无本地Git操作

## 4 硬性约束（不可更改）
1. 无后端、无服务器、无Nginx、无数据库
2. 所有API由Vue3前端直接调用GitHub官方接口
3. 所有凭证仅本地加密存储，不上云
4. 所有操作禁止跳转GitHub官网
5. 必须支持绿色主题 + 浅色 / 深色 / 跟随系统
6. 多账号永久常驻、无需切换登出

## 5 用户体验需求
1. 页面切换流畅、加载状态提示完整
2. 所有高危操作二次确认
3. Token失效自动检测、弹窗提示
4. 下载进度可视化
5. 系统主题变更实时生效

## 6 验收标准
1. 可无限绑定多GitHub账号，互不干扰、无需切换登录
2. 仓库设置、分支、Action、Release全部内置完成，无需浏览器
3. 绿色主题正常显示，深浅色、跟随系统切换正常
4. 三端功能一致，仅本地Git能力Windows独有
5. 所有下载闭环，零外链跳转
6. 数据全部本地存储，无隐私上传
